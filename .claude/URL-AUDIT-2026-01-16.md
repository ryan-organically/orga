# URL Strategy Audit Report
**Date:** 2026-01-16
**Version:** 1.0
**Auditor:** Claude Opus 4.5

## Executive Summary

A comprehensive audit of internal links reveals **335 violations** across 58 HTML files. Despite a commit on 2026-01-08 claiming to "Fix internal linking site-wide," only partial fixes were applied. The site remains in a broken state for users accessing pages with trailing slashes.

## Audit Findings

### Violation Breakdown

| Type | Count | Severity | Description |
|------|-------|----------|-------------|
| Relative `.html` links | 331 | **CRITICAL** | `href="page.html"` causes 404 on trailing-slash URLs |
| Absolute without trailing slash | 4 | HIGH | `href="/page"` causes 301 redirect |
| Absolute `.html` links | 0 | - | None found |

### Impact Analysis

**User Experience:**
- Users accessing `/seo-for-dentists/` (with trailing slash) who click `href="blog.html"` get 404
- The browser resolves relative link to `/seo-for-dentists/blog.html` which doesn't exist

**SEO Impact:**
- Broken internal links = crawl errors
- 301 redirects waste crawl budget
- Poor internal link equity distribution

### URL Resolution Rules

| Source File | Canonical URL | Direct Access Behavior |
|-------------|---------------|------------------------|
| `page.html` | `/page/` | `/page` 301 -> `/page/` |
| `es/page.html` | `/es/page/` | `/es/page` 301 -> `/es/page/` |

### Link Format Decision Tree

```
Is it an internal page link?
├── YES: Use absolute path with trailing slash: href="/page/"
│   ├── Never use: href="page.html" (relative, breaks)
│   ├── Never use: href="/page.html" (absolute .html, not canonical)
│   └── Avoid: href="/page" (works but causes 301)
└── NO (external, anchor, asset):
    └── Use appropriate format (https://, #anchor, /images/file.png)
```

## Appendix: Verification Commands

```bash
# Find relative .html links
grep -rn 'href="[a-z-]*\.html"' --include="*.html" .

# Find absolute links without trailing slashes (excluding assets)
grep -rn 'href="/[a-z-]*"' --include="*.html" . | grep -v '\.(css|js|png|jpg|svg|xml|json)'

# Count total violations
grep -rn 'href="[a-z-]*\.html"' --include="*.html" . | wc -l
```
